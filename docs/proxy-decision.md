# 代理决策逻辑（target / proxy / local / deny / auto）

本页把一条连接「走本地直连、走哪个代理、还是拒绝」的完整判定讲清楚。
实现在 `proto/tunnel.go` 的 handshake 阶段。

两个正交维度：

- **`target`**：出口策略——本地直连 / 走代理 / 自动 / 拒绝。
- **`proxy`**：走代理时用哪个代理（支持多代理与 `local`/`deny` 后缀）。

`target` 决定「要不要 / 何时用代理」，`proxy` 只回答「用代理时用哪个」。

---

## 一、target 取值

HTTP 用 `hosts[].target`，缺省取 `default.target`；纯 TCP 缺省取 `default.tcpTarget`。两者都没配时默认 `auto`。

| 值 | 含义 |
|----|------|
| `local` | **本地直连**（当前环境出网）。优先级最高，配了 `proxy` 也忽略 |
| `remote` | **走代理**（该条 `proxy`，没有则全局代理）。代理不可用且无 `local` 兜底时**报错**，不直连 |
| `auto` | **本地优先**：先直连，连不通再走代理。无论代理配在 host 还是全局都如此 |
| `deny` | **拒绝**该请求 |
| `localport` | 仅 `tcpTarget` 可用：命中 `default.localPort` 的端口走本地，其余走代理 |

> 说明：`proxy` 也被当作 `remote` 的同义写法（任何非 `local`/`auto`/`deny`/`localport` 的值都按「要走代理」处理）。推荐用 `remote`。

---

## 二、proxy 取值

覆盖全局代理。协议前缀 `tunnel://`（默认，不写前缀即此）/ `socks5://` / `http://`。

三种写法，`default.proxy`（及命令行 `-p`）与 `hosts[].proxy` **完全一致**：

```yaml
proxy: socks5://127.0.0.1:1080                              # 单代理
proxy: http://127.0.0.1:8888, http://127.0.0.1:7777        # 多代理：逗号分隔
proxy: http://127.0.0.1:8888, http://127.0.0.1:7777 local  # 多代理 + 兜底后缀
```

### 多代理

逗号分隔多个代理，**按顺序逐个做连通性探测（300ms 拨号），用第一个能连通的**。

### 后缀 `local` / `deny`

写在整串**末尾**，控制「列出的代理全都连不通时怎么办」：

| 后缀 | 全部代理都不可用时 |
|------|------------------|
| （无后缀）| host 代理：回退**全局代理**；全局代理：见下方“兜底”一节 |
| `local` | 忽略代理，**走本地直连** |
| `deny` | **拒绝**请求 |

---

## 三、完整决策顺序

对每条连接（已匹配到 host 规则或 default），**按 target 分流，代理是按需才解析/探测的**：

1. `target == deny` → 直接拒绝。
2. `target == localport` → 命中本地端口则视为 `local`，否则视为 `remote`。
3. `target == local` → **本地直连，完全不解析/探测代理**（也不受全局代理 `deny` 后缀影响）。
4. `target == auto` → **本地优先，先直连（2s 超时），此时还没碰代理**：
   - 直连成功 → 用直连，结束（代理一次都不探测）。
   - 直连失败 → 记“直连失败”短缓存（见缓存一节）→ 降级为 `remote`，继续第 5 步。
5. `target == remote`/`proxy`（含上一步降级而来）→ **选代理**（见“选代理流程”）：
   - 选到可用代理 → 走代理。
   - 代理都不可用：有 `local` 兜底 → 本地直连；否则 → **报错**（不静默直连）。

> 关键顺序：`auto` 的直连尝试在**代理解析之前**——直连能通就绝不去探测代理，代理挂着也不会拖慢它。只有直连失败才会去解析/探测代理。

### 选代理流程（host 优先，全局兜底）

```
if host.proxy 配了:
    在 host.proxy 上按「多代理 + 后缀」挑选:
        选到可用代理        -> 用它
        全挂 + 后缀 local   -> 走本地直连
        全挂 + 后缀 deny    -> 拒绝
        全挂 + 无后缀        -> 回退到全局代理(下面这段)
else 或需要回退:
    在全局代理(-p / default.proxy)上按「多代理 + 后缀」挑选:
        选到可用代理        -> 用它
        全挂 + 后缀 local   -> 走本地直连
        全挂 + 后缀 deny    -> 拒绝
        全挂 + 无后缀        -> 无更上级兜底
```

关键点：

- **host 代理先于全局代理尝试**；host 代理命中时根本不会去探测全局代理（不浪费拨号）。
- **`auto` 一律本地优先**，不会因为配了 proxy 就跳过直连——想强制走代理请用 `target: remote`。
- **无 `local` 后缀时，代理不通不会静默直连**。`target` 要走代理（`remote`/`proxy`）且配了代理却全不可用、又没有 `local` 兜底 → 报错。想让代理挂了退回本地，必须显式写 ` local`。

---

## 四、全局代理的取值与热加载

请求时**实时**读取全局代理，优先级：命令行 `-p`（固定，进程存活期不变） > 配置 `default.proxy`（**可热加载**，改配置文件即时生效）。

性能：普通**单个**全局代理走「无探测快路径」，不给每个请求加拨号；一旦配成**多代理或带后缀**，才按连通性逐个探测（与 host 代理一致）。

---

## 五、两个短缓存（都为 20s）

避免同一波并发请求重复做无用探测，同时保证故障快速恢复：

| 缓存 | 作用 | 时长 |
|------|------|------|
| **代理不可用缓存** | 某代理探测失败后标记不可用，有效期内跳过 300ms 拨号（多代理时立即试下一个）；探测成功立即清除 | `proxyFailTTL` = 20s |
| **auto 直连失败缓存** | `auto` 直连失败后，有效期内后续请求跳过直连直接走代理 | `autoDirectFailTTL` = 20s |

两者都刻意取短：一次偶发失败不会把域名长时间钉死在代理（或直连）上，过期后会重新尝试以便及时恢复。

---

## 六、常见组合速查

| target | proxy 配置 | 代理可用 | 代理全挂 |
|--------|-----------|---------|---------|
| `local` | 任意 | 本地直连 | 本地直连 |
| `auto` | 有 | 先直连，不通走代理 | 直连（代理是兜底，兜底也没了就直连） |
| `remote` | 无后缀 | 走代理 | 回退全局；全局也挂 → **报错** |
| `remote` | ` local` | 走代理 | **本地直连** |
| `remote` | ` deny` | 走代理 | **拒绝** |
| `deny` | — | 拒绝 | 拒绝 |

---

## 七、配置示例

```yaml
default:
  target: auto                     # 默认本地优先
  # 全局代理: 多代理 + local 兜底; 可热加载
  proxy: socks5://192.168.122.11:10808, socks5://192.168.122.33:10808 local

hosts:
  # 强制走代理; 该代理挂了不回退全局、直接拒绝
  - name: "*google.com"
    target: remote
    proxy: socks5://192.168.122.8:10808 deny

  # 本地优先: 先直连, 不通再用这个代理
  - name: "*github.com"
    target: auto
    proxy: http://127.0.0.1:8888

  # 强制走代理; 代理挂了退回本地直连
  - name: "*example.com"
    target: remote
    proxy: http://127.0.0.1:8888 local

  # 直接禁止
  - name: "*doubleclick.net"
    target: deny
```

---

## 八、易错点

- **只配 `proxy` 没配 `target`**：`target` 默认 `auto`（本地优先），此时可直连的站点不会走代理。要强制走代理请配 `target: remote`。
- **`remote` + 代理挂了以为会自动直连**：不会，会报错。需要退回本地请显式加 ` local` 后缀。
- **后缀位置**：`local`/`deny` 必须在整串**最后**，前面用空格分隔，如 `... :7777 local`。
- **“能用”= 能连通**：多代理挑选依据是 300ms 拨号探测能否连上，不是仅仅格式正确。
