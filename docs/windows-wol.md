# Windows 完整网络唤醒（WOL）配置教程

## 一、功能说明

网络唤醒（Wake on LAN，简称 WOL）是通过内网发送**魔术包（Magic Packet）**，让完全关机状态下的 Windows 电脑开机。  

核心原理：Windows 正常软关机后，网卡会保留 5V 待机供电，持续监听内网数据包，收到标准魔术包后触发主板上电开机。

## 二、Windows 网卡核心配置（设备管理器）

操作路径：右键开始菜单 → 设备管理器 → 网络适配器 → **有线网卡**（无线网卡不支持）→ 右键属性

### 1、电源管理选项卡（必须全部正确勾选）

✅ **允许计算机关闭此设备以节约电源**

✅ **允许此设备唤醒计算机**（必开）

✅ **只允许魔术包（幻数据包）唤醒计算机**（必开，防止误唤醒）

### 2、高级选项卡

找到网卡高级参数：**Wake on Magic Packet / 魔术包唤醒**

设置为：**启用**

（不同品牌网卡名称略有区别：Intel、Realtek、瑞昱均有对应魔术包唤醒开关，必须开启）

## 三、Windows 系统电源设置（解决 WOL 失效核心问题）

### 1、关闭「快速启动」（重中之重）

路径：控制面板 → 电源选项(左侧) → 选择电源按钮的功能 → 点击「更改当前不可用的设置」→ 取消勾选 **启用快速启动（推荐）**

说明：快速启动会让 Windows 并非完全关机，而是进入休眠状态，直接导致网卡待机监听失效、WOL 魔术包无法唤醒主机。

### 2、高级电源计划设置

路径：电源选项 → 更改计划设置 → 更改高级电源设置

1）睡眠 → **允许混合睡眠：关闭**

2）PCI Express → **链接状态电源管理：关闭**

作用：防止系统和 PCIe 总线节能机制切断网卡待机供电，保证关机后网卡持续在线监听数据包。

## 四、主板 BIOS 必配设置（最容易被忽略、决定能否唤醒）

开机按 Del / F2 / F10 进入主板 BIOS 设置

1、开启网络唤醒：**Wake On LAN / Power On By PCI\-E / PCIE Wakeup = Enabled**

2、关闭节能断电：**ErP / EuP / ErP Ready = Disabled（关闭）**

**关键说明：ErP 节能模式开启后，主机关机直接彻底切断网卡 5V 待机供电，网卡完全停止工作，绝对无法接收魔术包，WOL 100% 失效。所有要做网络唤醒的电脑必须关闭 ErP。**

设置完成按 F10 保存并重启电脑。

## 五、硬性使用条件（缺一不可）

1、**必须使用有线网卡**：无线网卡绝大多数硬件不支持关机 WOL 唤醒，仅有线网卡具备待机供电与监听能力。

2、电脑必须**保持通电**：电源线不能拔掉、不能关闭插排开关，必须保证主板待机供电。

3、网线必须正常插紧：关机后网卡指示灯常亮，代表网卡待机工作正常，可以接收唤醒包。

4、必须 Windows 系统内**软关机**：长按电源键硬关机、断电重启会导致 WOL 待机状态异常。

5、唤醒设备（UBNT 路由）与 Windows 主机必须在**同一局域网**。
